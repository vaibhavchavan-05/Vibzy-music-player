# 🎵 Vibzy Music Player

Vibzy Music Player is a full stack web-based music streaming application developed as part of my internship project. The application provides a smooth and user-friendly music playback experience with features such as search, playlists, and playback controls.

---

## 🚀 Features
- Play, pause, next, previous music controls
- Search songs by title or artist
- Playlist creation and management
- Responsive user interface
- Frontend–backend integration

---

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript, React  
**Backend:** Node.js, Express.js
